# Solana Blockhash Transaction Expiration

This Python script simulates the 'Transaction Expired' error in Solana by demonstrating how an outdated blockhash causes a transaction to become invalid. It highlights the importance of using a current blockhash for successful transaction submission.

## Language

`python`

## How to Run

Run this script using Python: `python solana_blockhash_demo.py`.
